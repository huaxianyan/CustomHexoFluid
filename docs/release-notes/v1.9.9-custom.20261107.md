基于 Fluid v1.9.9 的标准版快照。图标字体跟着页面一起下发，导航图标不再等外部 CDN；正文图片的占位图改为独立目录存放；另修掉两套图标字体撞名导致的字形错乱。

## 新功能

- **图标字体内联**：两套图标字体随页面下发，图标不再等外链 CSS 与随后的字体请求，不会出现「文字先出来、图标闪一下」。
- **占位图改读 `proc/` 子目录**：占位图与原图分开放，只维护原图，WebP / AVIF 变体由规则生成。

## 问题修复

- **图标字形错乱**：两套图标字体的 family 同名时，后加载的一套覆盖前一套，「时间线」「奖杯」等图标会显示成别的字形。现在两套字体各自独立。
- **图标样式表尾部空行**：Hexo 仓库的空白检查会拒绝带尾部空行的文件，导致主题同步失败。
- **本地搜索输出不确定**：同一份内容多次构建会得到不同的搜索结果文件，改用稳定排序。

## 说明

字库里的 117 个图标全部可用，导航与社交的默认图标无需额外配置。升级只需替换主题目录，配置文件不用改动。

完整实现与验收记录见 [README 的分支说明](https://github.com/huaxianyan/CustomHexoFluid/blob/v1.9.9-custom.20261107/README.md)。
